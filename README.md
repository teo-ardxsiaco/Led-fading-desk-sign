# Led-fading-desk-sign
This project started as a heartfelt, custom-made desk gift for my girlfriend, using an LM358, not rail-to-rail.
The signal, generated by a Schmitt Trigger, can be sampled as integrated between the capacitor and the upper resistance of the configuration, to be carried to the base of the TIP122 and obtain the fading.
